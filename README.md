# GBIF Occurrence Data Processing

This project is focused on processing Scleractinia occurrence data from the **Global Biodiversity Information Facility (GBIF)**. The goal is to clean, organize, and merge this data with taxonomy and status updates to generate useful datasets for further research. This script allows for filtering, batching, and processing GBIF occurrence data, taxonomy information, and specimens.

## Project Structure

- **GBIF Occurrence Data Processing**: The main R script that performs the data processing.
- **Figures**:The main R script that performs the figures.
- **NHMUKPortal26feb.csv**: The raw NHMUK Data Portal obtained after filtering by "scleractinia".
- https://www.gbif.org/occurrence/download/0022573-250127130748423 link for the initial GBIF dataset
